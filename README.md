# Kami Groupe — Tableau de bord

Tableau de bord personnel pour piloter les activités d'apporteur d'affaires :

- **CEE** — certificats d'économie d'énergie
- **Énergie** — fournisseurs d'énergie pour les pros
- **Taxe foncière** — récupération pour les professionnels

## Fonctionnalités

- **Tableau de bord** : dossiers actifs, commissions potentielles / à encaisser / encaissées, vue par activité, tâches du jour et en retard.
- **Planning** : semaine en cours, RDV et tâches, relances de dossiers affichées automatiquement.
- **Dossiers** : suivi des prospects et clients (Prospect → RDV → Étude → Signé → Payé / Perdu), filtres et recherche.
- **Commissions** : suivi des montants signés et reçus.
- **Paramètres** : nom affiché, export / import de sauvegarde.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (Settings → Pages → branche `main`, dossier `/`).

Les données sont enregistrées **uniquement dans le navigateur** (localStorage). Exporter régulièrement une sauvegarde depuis Paramètres.
